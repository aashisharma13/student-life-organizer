# Student Life Organizer 📚

A beginner-friendly Python project designed to help students manage everyday academic and personal tasks in one place.

## Features

* Add and view assignments with deadlines
* Add and view expenses
* Calculate total expenses
* Track attendance percentage
* Get a warning when attendance is below 75%
* Add and view personal notes
* Save data automatically using JSON
* Basic input validation and error handling

## Technologies Used

* Python
* JSON
* File Handling
* Lists and Dictionaries
* Functions
* Loops and Conditional Statements
* Exception Handling

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in Terminal.
4. Run:

```bash
python3 student_life_organizer.py
```

5. Follow the menu displayed in the terminal.

## Data Storage

The project automatically creates a `student_data.json` file to store assignments, expenses, attendance records, and notes.
